    TANGGAP DARURAT

    Apa yang harus dilakukan.

    Langkah praktis menghadapi kebakaran hutan dan lahan, dari persiapan sampai pasca-kejadian.

    01 Sebelum — bersiap +
    • Kenali jalur evakuasi dan titik kumpul terdekat dari rumah.
    • Siapkan tas siaga (lihat checklist di bawah) dan simpan di tempat mudah dijangkau.
    • Pantau informasi resmi BMKG, BNPB, dan pemerintah daerah.
    • Catat nomor darurat keluarga dan tetangga rentan (lansia, bayi, disabilitas).
    02 Saat — bertindak +
    • Segera hubungi 112 dan laporkan lokasi serta arah asap.
    • Matikan listrik dan gas, jangan biarkan api terbuka menyala.
    • Jangan mencoba memadamkan api yang sudah besar — fokus ke evakuasi.
    • Ikuti arahan petugas; jangan menembus asap untuk mengambil barang.
    03 Setelah — waspada +
    • Jangan memasuki area bekas terbakar sampai dinyatakan aman oleh petugas.
    • Waspadai bara tersembunyi — lahan gambut bisa menyala kembali berhari-hari.
    • Gunakan masker saat membersihkan abu; jaga ventilasi dan air bersih.
    • Catat kerusakan dan laporkan untuk bantuan serta pemulihan.

    ARAH ASAP

    Baca arah asap.

    Asap dan api bergerak mengikuti arah angin. Bergeraklah melawan arah angin atau tegak lurus terhadap asap — jangan menembusnya.

    1. Bergerak melawan arah angin atau tegak lurus arah asap, bukan menembus asap.
    2. Turun ke lereng bawah — api menjalar jauh lebih cepat ke arah atas (menanjak).
    3. Hindari lembah, jurang, dan alur sungai kering — berfungsi seperti cerobong api.
    4. Jangan menyeberangi punggungan atau bukit yang masih terbakar di baliknya.
    5. Cari area terbuka: lapangan, jalan, badan air, atau area yang sudah terbakar.
    6. Jika terjebak asap: tetap rendah (asap dan panas naik), basahi kain dan tutup hidung serta mulut.

    Panduan umum, bukan pengganti arahan resmi BNPB/BMKG atau petugas di lapangan. Selalu utamakan instruksi otoritas setempat.

    MITOS & FAKTA

    Yang sering keliru.

    ? "Membakar lahan kecil itu aman." +

    Mitos. Api kecil di lahan gambut bisa menyebar di bawah permukaan dan muncul kembali jauh dari titik awal, sering berhari-hari kemudian.

    ? "Merangkak rendah selalu paling aman." +

    Tidak selalu. Menunduk membantu untuk asap tipis, tetapi pada api besar panas radiasi dan bahan bakar di permukaan justru lebih berbahaya — prioritaskan menjauh dari arah api dan angin.

    ? "Hujan berarti sudah aman." +

    Belum tentu. Hujan singkat tidak selalu memadamkan api di gambut. Bara di bawah permukaan bisa tetap panas dan menyala kembali saat kering.
